# Function Grapher

An interactive, browser-based function plotter. Enter algebraic expressions in terms of `x`, toggle derivative overlays, snap sampling to integers, and export the result as a PNG. Everything runs client-side—open `index.html` directly to start graphing.

## Features
- Multiple function rows with custom colors and stroke widths.
- Optional derivative traces per function.
- Adjustable domain, sampling density, and grid visibility.
- Quick evaluation for all functions at a chosen `x` value.
- Export current view to PNG.

## Usage
Open `index.html` in a modern browser. Type expressions using math.js syntax (e.g., `sin(x)`, `e^x`, `sqrt(x^2 + 1)`). Pan or zoom inside the Plotly chart and use the controls to adjust the viewport or sampling.
